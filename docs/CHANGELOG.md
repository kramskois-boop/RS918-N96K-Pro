# История изменений

Формат — по мотивам Keep a Changelog; версии соответствуют тегам git.
Для этого репозитория: `2.9.48` (база upstream) → `nizar-baseline` (импорт дерева Nizar) →
`cleanup-done` (чистка) → `v1.0` (готовится).

## [Unreleased] → v1.0

Дата не назначена: прошивка готовится к передачи и полевым испытаниям. Статусы патчей —
в [PATCHES.md](PATCHES.md).

### Добавлено

- **Идентификация продукта** (`src/uhsdr_version.h`, P0-6): `UHSDR_PRODUCT_NAME` =
  `"RS918 N96K-Pro"`, `UHSDR_PRODUCT_VERSION` = `"2.9.48-n96kp1"`, `UHSDR_PRODUCT_REPO`;
  восстановлен `UHSDR_REPO` = `github.com/df8oe/UHSDR`. На устройстве («System Info») теперь
  отображается `2.9.48-n96kp1`; числовая версия 2.9.48 сохранена.
- **Документация**: продуктовый [README](../README.md), [PATCHES.md](PATCHES.md),
  [CHANGELOG.md](CHANGELOG.md), [SAFETY.md](SAFETY.md), [CREDITS.md](CREDITS.md),
  [BUILD.md](BUILD.md) (сборка/прошивка/диагностика).
- **CLI-сборка** (P0-2): `tools/build.py` — воспроизводимая сборка `fw-mchf` и `bl-mchf`
  без Eclipse/make, читает те же `*.mak`, что и Makefile; установка и артефакты — BUILD.md.
- **Гигиена репозитория** (P1-1): `.gitattributes` (`text=auto`, LF для исходников и
  документации), расширенный `.editorconfig`.

### Исправлено (дефекты аудита 2026-11-26)

- **P0-1. EEPROM/конфигурация:** мёртвая проверка диапазона (`&& 0xff` → `& 0xff`),
  проброс ошибки ConfigStorage, клампы band/demod/decod — исключены чтение/запись за границей
  массивов при сбое или битой EEPROM.
- **P0-3. Аудио:** инициализация NR-буфера (мусор в ЦАП), устранено UB в TX-реверберации,
  `abs()` → `fabsf()` для float-значений.
- **P0-4. PA/КСВ:** guard деления на ноль при измерении КСВ; портирован foldback PA по КСВ
  с гистерезисом — PA защищён при КЗ/обрыве антенны.
- **P0-5. TX-безопасность:** запрет смены бэнда/фильтра по CAT во время передачи;
  включён программный запрет TX вне любительских диапазонов, восстановлен пункт меню.
- **P0-2. Сборка:** `iir_2_8k.c` и `iir_16k5_96ks.c` внесены в `*.mak`; устранены блокеры
  сборки на GCC 10+.

### Изменено

- `README.md` заменён с upstream-текста на описание продукта; суть upstream (что такое UHSDR,
  происхождение mcHF, GPLv3) сохранена в разделе «Что это» и «Лицензия и атрибуция».
- Версия в прошивке: `UHSDR_VERSION` теперь производная от `UHSDR_PRODUCT_VERSION`
  (`fwv-2.9.48-n96kp1`); числовые `UHSDR_VER_*` не менялись. `UHSDR_BOOT_VERS` = 4.1.2.
- Дерево очищено от мусора сборки, RAR/IDE/CI-хлама; поддержка F7/H7 исключена из сборки.

### Не вошло в v1.0

- **P2-1.** Бэкпорты upstream: Hamlib 4.3 CAT (`get_vfo`, FT-817/WINTEST), FreeDV/Codec2 rev 4121
  и #1749, AGC restore #1730, Tune Power #1750, CW-декодер #1881, EEPROM signature #1675,
  DMA size #1664.
- **P2-2.** CI и фиксированный тулчейн, автоматический контроль бюджета flash/CCM.
- Полный merge на upstream 2.12.2 (см. README, «Ограничения»).

### Известные ограничения

Кратко — в [README](../README.md), правила эксплуатации — в [SAFETY.md](SAFETY.md). Главное:
база 2.9.48 (не 2.12.2), только F4/mcHF, CCM заполнена почти полностью, настройки EEPROM
несовместимы с другими сборками UHSDR.

## [nizar-baseline] — импорт дерева Nizar (тег `nizar-baseline`)

Импортировано рабочее дерево форка Nizar (3V8MN) поверх официального UHSDR 2.9.48 (`ae93edf6`):
150 изменённых файлов, 2 новых файла фильтров, +38 906 / −19 299 строк; доработки 96 кГц RX /
12 кГц TX, ЦОС-слой `*_Nizar`, фильтры, аудио-тракт, UI, USB/CAT, расширенная раскладка EEPROM.
Функциональность сохранена без откатов; полная инвентаризация — во внешнем отчёте аудита (вне репозитория).

## [cleanup-done] — чистка (тег `cleanup-done`)

Удалены артефакты сборки Eclipse (414,6 МБ), RAR-снапшоты, `.svn`-остатки, дубли, сгенерированные
графы и картинки, тестовые дампы; из сборки исключены вендорные платформы F7/H7. Исходный код
прошивки не изменялся. Состав чистки фиксируется отдельным коммитом.
