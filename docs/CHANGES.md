# Сводная таблица изменений: UHSDR 2.9.48 (форк Nizar) → RS918 N96K-Pro v1.2

**Что было:** архив-папка UHSDR_2_9_48_Tx_12Khz_Rx_96Khz_integer — рабочая копия официального UHSDR v2.9.48 (ae93edf6, 2018) с доработками Nizar (3V8MN) «Tx 12 кГц / Rx 96 кГц integer», без git-коммитов, с 414,7 МБ артефактов сборки и сопутствующим мусором.

**Что стало:** самостоятельный продукт **RS918 N96K-Pro** — git-репозиторий с тегами **v1.0 / v1.1 / v1.2**, воспроизводимой CLI-сборкой, релизными артефактами и документацией. Все доработки Nizar сохранены; добавлены патчи качества и безопасности (P0/P1/A) и бэкпорты upstream (P2).

## 3. Что осталось (ограничения v1.2)

- **На железе не испытывалось**: нужны полевые тесты по docs/TESTPLAN.md (VSWR-защита и ложные срабатывания, загрузчик 5.0.4 USB/DFU, NR, Tune Power, USB-аудио, CAT).
- **FreeDV в сборке выключен** (IS_SMALL_BUILD, как и в форке); vendor обновлён — включение отдельным этапом (-DUSE_FREEDV, бюджет RAM/flash, стенд).
- **CI не исполнялся** end-to-end: нет Docker на машине разработки и нет собственного remote-репозитория.
- Остаточные P3: ложные trip на фронте TX (стенд), периодические recovery-пробы в гистерезисе (нагрев/ЭМС), поддержка F7/H7 не удалена (57 МБ vendor, решение отдельно), нет полевых логов.
