## 3. TX (эквивалент 50 Ом)

- [ ] Уровни 0.5 / 1 / 2 / 5 Вт / Full выставляются и видны в PWR
- [ ] Tune Power: после выхода из Tune мощность и PWR восстановлены
- [ ] AM: G3 roll-over после 0.5W даёт 2W (FULL/5W в AM не выбираются), факт проверен ваттметром
- [ ] CW: ключ, sidetone, скорость, самостоятельная передача; CW-USB↔CW-R (H3) дают зеркальные стороны
- [ ] H2: после Load Defaults — Mic 15, Comp In 1.0, Comp Out 1.0, TX Treble +2.0 dB, EQ CUSTOM; long-press reset даёт те же значения
- [ ] H2: спектр/IMD TX на речи и двухтоне — без широкого сплэттера и «каши»; ALC не залипает; при резкости уменьшить TX EQ mid
- [ ] H9: частота TX SSB совпадает с индикацией/CAT (нулевые биения; дефолт сдвига 0 Гц, явная опция −15…+5 Гц в меню)
- [ ] H1: 10 м — на 26.8/27.0/27.5 передачи нет, на 28.0/28.5/29.6 есть, на 29.8 (GEN) нет
- [ ] H1: 4 м 70.4 есть / 70.6 нет; 2 м 144.0/145.9 есть / 142.5/143.9 нет; 70 см 430/439.9 есть / 415/445 нет
- [ ] H1: Tune на 27.5 не включается, на 28.5 работает; SPLIT TX вне участка — индикация оранжевая, PTT не клюёт
- [ ] H1: override «TX on Out-Of-Band Freq.» — на 27.0 TX только при включении; мощность автоматически НЕ ограничивается (обычная per-band, до клампа 0.55) — выставить 0.5 Вт вручную, только эквивалент; после OFF снова запрещён
- [ ] Нет самовозбуждения/помех, нагрев в норме

## 4. VSWR-защита (Configuration → VSWR Protection; default 3)

- [ ] 50 Ом: защита не срабатывает, SWR! нет
- [ ] КСВ≈2: foldback — мощность падает до минимальной, виден SWR!, bias снимается
- [ ] Обрыв антенны: foldback быстро (~60 мс), SWR!, без полного драйва
- [ ] КЗ (кратковременно, малая мощность): foldback, без повреждения PA
- [ ] Возврат на 50 Ом: восстановление ~1 с, уровень пользователя вернулся
- [ ] A1: вращение PWR-энкодера в foldback НЕ поднимает мощность
- [ ] Порог 1 (OFF): при высоком КСВ защиты нет (проверять только на эквиваленте!)

## 6. Диагностика и регрессия

- [ ] DEBUG-меню: Audio ISR max load < 70 % периода, DMA late/err = 0, NR under/overrun = 0 за 10 мин RX/TX
- [ ] Меню/энкодеры/тачскрин/виртуальная клавиатура работают
- [ ] H13-остаток: 20+ переключений бэнда с включённым NR/DNR — без провалов/залипаний (сброс DSP на band switch не убран, стендовая проверка)
- [ ] Повторные power-cycle без зависаний и самопроизвольных сбросов
- [ ] Нет посторонних шумов/треска в RX/TX при переключениях (насколько слышно)
- [ ] H4: PLL Reset default 2; смена IQ-делителя/бэнда без спуров и ухода частоты («Never» — только опция стенда)
- [ ] H6: AGC FAST/MED/SLOW/LONG + OFF Gain — без пумпинга/«выдыхания»; меню AGC Mode/Threshold доступны, Hang-пунктов нет (осознанно)
- [ ] H10: CW-декодер на 20–80 WPM без ошибок (при blocksize 32 — выше); сравнить с B6-базой

- [ ] H8 (стенд): RF-гейн монотонен, на максимуме нет перегруза АЦП и «прыжков» громкости; AUTO не рестартует I2S на каждом шаге
- [ ] H12 (решение): не считать дефектом до решения lead — noise gate не включён (следы в EEPROM), VID/PID 0x0963/0x5733 или 0x2341/0x8036 (bit2 реверба); проверить энумерацию Win/Linux/Android
