## 0. До прошивки

- [ ] Сверены SHA-256 и размеры файлов из приложенного SHA256SUMS.txt (release/v1.2 — 13/13; для тестового пакета — все файлы пакета)
- [ ] Записан текущий откат: старая прошивка (или fw-mchf.old) и значения меню сохранены
- [ ] Флешка FAT32, выбранный fw-mchf.bin в корне, других .bin в корне нет

## 1. Прошивка (USB-флешка через загрузчик)

- [ ] Выключить, зажать BAND−, включить питание
- [ ] Экран: mcHF QRP Bootloader / Firmware Name: fw-mchf / USB Drive Mode
- [ ] Вставлена флешка → USB Drive detected.
- [ ] Появилось Updating firmware using "fw-mchf.bin"... (BAND− отпущена)
- [ ] Finished. → перезагрузка; на флешке есть fw-mchf.old
- [ ] System Info → Firmware = 2.9.48-n96kp3
- [ ] System Info → Bootloader = 5.0.4
- [ ] System Info → Build соответствует дате сборки (для тестового пакета — Build из его README)

## 2. RX (приём)

- [ ] Спектр/панорама 96 кГц, waterfall, zoom работают
- [ ] Перестройка частоты, шаги, VFO A/B
- [ ] NR: вкл/выкл, шум/сигнал изменяются предсказуемо, без зависаний
- [ ] Фильтры 300 Гц … 2.9 кГц переключаются
- [ ] Режимы USB/LSB/CW/AM/FM переключаются
- [ ] Настройки сохранились после выключения/включения питания

## 3. TX (эквивалент 50 Ом)

- [ ] Уровни 0.5 / 1 / 2 / 5 Вт / Full выставляются и видны в PWR
- [ ] Tune Power: после выхода из Tune мощность и PWR восстановлены
- [ ] AM: G3 roll-over после 0.5W даёт 2W (FULL/5W в AM не выбираются), факт проверен ваттметром
- [ ] CW: ключ, sidetone, скорость, самостоятельная передача
- [ ] Нет самовозбуждения/помех, нагрев в норме

## 4. VSWR-защита (Configuration → VSWR Protection; default 3)

- [ ] 50 Ом: защита не срабатывает, SWR! нет
- [ ] КСВ≈2: foldback — мощность падает до минимальной, виден SWR!, bias снимается
- [ ] Обрыв антенны: foldback быстро (~60 мс), SWR!, без полного драйва
- [ ] КЗ (кратковременно, малая мощность): foldback, без повреждения PA
- [ ] Возврат на 50 Ом: восстановление ~1 с, уровень пользователя вернулся
- [ ] **A1:** вращение PWR-энкодера в foldback НЕ поднимает мощность
- [ ] Порог 1 (OFF): при высоком КСВ защиты нет (проверять только на эквиваленте!)

## 5. CAT / USB

- [ ] WSJT-X/Hamlib 4.3: get_vfo, PTT, смена частоты в RX
- [ ] Смена бэнда по CAT во время TX игнорируется (LPF не щёлкает под мощностью)
- [ ] USB Audio 96 кГц: устройство видно, запись/воспроизведение без underrun

## 6. Диагностика и регрессия

- [ ] DEBUG-меню (сборки main + B3): Audio ISR max load < 70 % периода, DMA late/err = 0, NR under/overrun = 0 за 10 мин RX/TX
- [ ] Меню/энкодеры/тачскрин/виртуальная клавиатура работают
- [ ] Повторные power-cycle без зависаний и самопроизвольных сбросов
- [ ] Нет посторонних шумов/треска в RX/TX при переключениях (насколько слышно)
