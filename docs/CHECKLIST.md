**Условия и безопасность.** Антенна заменена эквивалентом 50 Ом (≥5 Вт); БП стабилен; передача не ведётся без нагрузки; перед прошивкой сделан бэкап прошивки и настроек. Загрузчик 5.0.4 не прошивать без ST-Link. Не передавать вне разрешённых диапазонов; TX-границы H1 проверять только на эквиваленте.

> Актуально для релиза v1.2 (release/v1.2) и тестовых сборок второй волны (ветка nizar-review): default fw 323 096 Б, FreeDV opt-in 566 616 Б, full opt-in 572 664 Б, bl 31 620 Б. SHA-256 и размеры берите из приложенного SHA256SUMS пакета, а не из бланка: после misc-фиксов H4/H6/H9–H12 числа изменятся. Стендовые риски: H1 (TX-границы), H2 (спектр TX), H5 (USB-аудио), H7 (пороги ADC-clip), H8 (кривая RF-гейна), H4 (PLL reset), H6 (AGC), H9 (сдвиг +15 Гц), H11 (CAT PWR/SWR), H12 (VID/PID).

- [ ] Сверены SHA-256 и размеры файлов из приложенного SHA256SUMS.txt (release/v1.2 — 13/13; для тестового пакета — все файлы пакета)
- [ ] Записан текущий откат: старая прошивка (или fw-mchf.old) и значения меню сохранены
- [ ] Флешка FAT32, выбранный fw-mchf.bin в корне, других .bin в корне нет
- [ ] H2: решено, как обновлять TX-аудио — Configuration → Load Defaults (сбросит все настройки) или вручную: Mic 15, Comp In 1.0, Comp Out 1.0, Treble +2.0 dB, EQ CUSTOM

- [ ] Появилось Updating firmware using "fw-mchf.bin"... (BAND− отпущена)

- [ ] System Info → Firmware = 2.9.48-n96kp3
- [ ] System Info → Bootloader = 5.0.4
- [ ] System Info → Build соответствует дате сборки (для тестового пакета — Build из его README)

## 2. RX (приём)

- [ ] Спектр/панорама 96 кГц, waterfall, zoom работают
- [ ] Перестройка частоты, шаги, VFO A/B
- [ ] NR: вкл/выкл, шум/сигнал изменяются предсказуемо, без зависаний
- [ ] Фильтры 300 Гц … 2.9 кГц переключаются
- [ ] Режимы USB/LSB/CW/AM/FM переключаются
- [ ] H3: меню CW LSB/USB Select = USB/LSB/AUTO; длинное нажатие Mode в CW переключает сторону (CW-R/CW-USB)
- [ ] H1: приём на расширенных участках Nizar (27, 143, 70.6, 415 МГц) не сломан
- [ ] Настройки сохранились после выключения/включения питания

## 3. TX (эквивалент 50 Ом)

- [ ] Уровни 0.5 / 1 / 2 / 5 Вт / Full выставляются и видны в PWR
- [ ] Tune Power: после выхода из Tune мощность и PWR восстановлены
- [ ] AM: G3 roll-over после 0.5W даёт 2W (FULL/5W в AM не выбираются), факт проверен ваттметром
- [ ] CW: ключ, sidetone, скорость, самостоятельная передача; CW-USB↔CW-R (H3) дают зеркальные стороны
- [ ] H2: после Load Defaults — Mic 15, Comp In 1.0, Comp Out 1.0, TX Treble +2.0 dB, EQ CUSTOM; long-press reset даёт те же значения
- [ ] H2: спектр/IMD TX на речи и двухтоне — без широкого сплэттера и «каши»; ALC не залипает; при резкости уменьшить TX EQ mid
- [ ] H1: 10 м — на 26.8/27.0/27.5 передачи нет, на 28.0/28.5/29.6 есть, на 29.8 (GEN) нет
- [ ] H1: 4 м 70.4 есть / 70.6 нет; 2 м 144.0/145.9 есть / 142.5/143.9 нет; 70 см 430/439.9 есть / 415/445 нет
- [ ] H1: Tune на 27.5 не включается, на 28.5 работает; SPLIT TX вне участка — индикация оранжевая, PTT не клюёт
- [ ] H1: override «TX on Out-Of-Band Freq.» — на 27.0 TX только при включении, после OFF снова запрещён (только эквивалент)
- [ ] Нет самовозбуждения/помех, нагрев в норме

## 4. VSWR-защита (Configuration → VSWR Protection; default 3)

- [ ] 50 Ом: защита не срабатывает, SWR! нет
- [ ] КСВ≈2: foldback — мощность падает до минимальной, виден SWR!, bias снимается
- [ ] Обрыв антенны: foldback быстро (~60 мс), SWR!, без полного драйва
- [ ] КЗ (кратковременно, малая мощность): foldback, без повреждения PA
- [ ] Возврат на 50 Ом: восстановление ~1 с, уровень пользователя вернулся
- [ ] A1: вращение PWR-энкодера в foldback НЕ поднимает мощность
- [ ] Порог 1 (OFF): при высоком КСВ защиты нет (проверять только на эквиваленте!)

## 5. CAT / USB

- [ ] WSJT-X/Hamlib 4.3: get_vfo, PTT, смена частоты в RX
- [ ] Смена бэнда по CAT во время TX игнорируется (LPF не щёлкает под мощностью)
- [ ] H3 CAT: MODE_SET 0x02 → CW-USB, 0x03 → CW-R (LSB); MODE_GET возвращает 2/3; сторона передачи меняется
- [ ] H5 USB Audio 96 кГц: устройство видно, запись/воспроизведение без underrun; микрофон stereo L=R без артефактов
- [ ] H5 USB-TX (DIG/цифра): звук без «рваных» дропов при дрейфе клоков; overflow не растёт в норме (DEBUG/отладчик)
- [ ] H11 (после misc): FT-817 TX_STATE отдаёт реальные PWR/SWR nibble; CW/CW-R различаются

## 6. Диагностика и регрессия

- [ ] DEBUG-меню: Audio ISR max load < 70 % периода, DMA late/err = 0, NR under/overrun = 0 за 10 мин RX/TX
- [ ] Меню/энкодеры/тачскрин/виртуальная клавиатура работают
- [ ] Повторные power-cycle без зависаний и самопроизвольных сбросов
- [ ] Нет посторонних шумов/треска в RX/TX при переключениях (насколько слышно)
- [ ] H4 (после misc): PLL Reset default 2; смена IQ-делителя/бэнда без спуров и ухода частоты («Never» — только опция стенда)
- [ ] H6 (после misc): меню AGC Mode/Threshold/Hang доступны, дефолты upstream-профиля; без пумпинга/«выдыхания»
- [ ] H9 (после misc): частота TX SSB совпадает с индикацией/CAT (нулевые биения, скрытого сдвига +15 Гц нет)
- [ ] H10 (после misc): CW-декодер на 60–90 WPM без ошибок (жёсткий лимит длительности снят/снижен)
